# 变更检查清单

每次提交或合并前按实际范围勾选。未涉及的项目可以标记为不适用，但不能直接删除。

## 行为与兼容性

- [ ] 已确认改动属于 `main` 通用功能还是 `production` 私有覆盖层。
- [ ] 未修改用户没有授权修改的功能。
- [ ] 页面、API、配置和数据兼容性已检查。
- [ ] 真实 Wolfx 地震处理和推送链路没有被测试实现替换。
- [ ] Bark Key 未进入 URL path、query、日志或公开文档。

## 测试

- [ ] `go test ./...` 通过。
- [ ] `git diff --check` 通过。
- [ ] 前端脚本语法和关键浏览器流程已验证。
- [ ] 部署检查使用隔离环境，没有影响现有生产服务器、域名、数据库或用户。

## 文档

- [ ] 用户可见行为变化已更新 README 或对应行为契约。
- [ ] 配置、依赖或部署变化已更新部署文档和示例文件。
- [ ] 分支或发布流程变化已更新 `BRANCH_AND_RELEASE_WORKFLOW.md`。
- [ ] PR/提交说明明确记录了验证结果、风险和回滚方法。
